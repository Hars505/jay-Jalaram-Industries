# Jay Jalaram Industries

Precision parts manufacturer in Ahmedabad since 1983 — CNC milled, turned, and ground gears, shafts, and bushes.

## Development

To set up and run the application locally:

```sh
npm install
npm run dev
```

## Built With

- TanStack Start & TanStack Router
- React 19
- TypeScript
- Tailwind CSS
- Vite
